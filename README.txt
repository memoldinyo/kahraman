KAHRAMAN – time tracking that asks
==================================

Kahraman lives as a small clock in the notification area of the taskbar (bottom
right, possibly behind the ^ arrow) and asks at an adjustable interval what you are
working on. The evaluation then shows how much time went into what.

Languages: German, English, Turkish, French, Italian, Arabic, Chinese and Russian.
Kahraman follows the Windows language; change it under Settings > General > Language.

Appearance: light, dark or same as Windows (Settings > General > Appearance).

INSTALLATION
------------
1. Unpack the ZIP and start Kahraman.exe.
2. If Windows shows "Windows protected your PC": click "More info" -> "Run anyway".
   The program is not (yet) digitally signed.
3. Answer "Install Kahraman?" with Yes and accept the license terms.
   Kahraman is copied to %LOCALAPPDATA%\Programs\Kahraman, gets a Start menu entry
   and starts automatically when you sign in. No administrator rights and nothing
   else is required. "No" starts Kahraman just this once without installing.

On first start Kahraman asks for the folder for your data
(suggestion: Documents\Kahraman Time Tracking, depending on the language).

UPDATING
--------
Simply start the new Kahraman.exe and confirm the update. Your data is kept.

UNINSTALLING
------------
Windows Settings -> Apps -> "Kahraman Time Tracking" (or the name in your language)
-> Uninstall.
Your data (log file and activities) is kept.

QUICK GUIDE
-----------
* Right-click the clock to open the menu; double-click means "Log now".
* An entry stands for the time since the previous entry. The first entry of a day
  only marks the start of work (e.g. "Start").
* The activity is required, sub-activity and comment are optional.
* The comment field is usually collapsed (the lists are wider then) and expands by
  itself if there is a comment for the selected project. The narrow bar on the far
  right (or Alt+K) expands and collapses it by hand.
* The sub-activities can be collapsed the same way (strip next to them or Alt+U).
  When collapsed they only appear if one is suggested for the activity; Kahraman
  remembers whether you last expanded or collapsed them.
* The question cannot be closed; it only goes away with an entry.
* F3 in the activity field searches the list; right-click in the lists colours or
  deletes entries.
* "Report..." shows hours and days (8 h) per week, month, quarter and year.
* Detailed help: menu "Help...".
